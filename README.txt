MPI TEKS DESKRIPSI — PETUNJUK PENGGUNAAN

Isi ZIP:
- index.html : aplikasi MPI interaktif, dapat dibuka langsung di browser.
- README.txt : petunjuk penggunaan.

CARA MENJALANKAN OFFLINE
1. Ekstrak ZIP ke sebuah folder.
2. Buka file index.html menggunakan Chrome, Edge, Firefox, atau browser modern.
3. Tidak perlu instalasi, server, internet, atau pustaka tambahan.
4. Gunakan menu untuk berpindah bagian: Apersepsi, Asesmen awal, Materi pokok, Simulasi, Kuis, Asesmen akhir, dan Refleksi.

CARA MEMBUAT ONLINE
- Unggah file index.html ke layanan hosting statis yang mendukung HTML (misalnya GitHub Pages, Netlify, atau hosting sekolah).
- Untuk layanan yang meminta folder proyek, unggah folder hasil ekstraksi; pastikan index.html berada di folder utama.
- ZIP ini tidak memerlukan proses build.

CATATAN
- Materi disusun sebagai contoh umum Bahasa Indonesia tingkat SMP dan dapat disesuaikan dengan kelas/kurikulum sekolah.
- Skor dihitung di browser. Jawaban tidak dikirim ke guru/server dan tidak disimpan permanen setelah halaman ditutup atau dimuat ulang.
- Untuk penilaian resmi, guru tetap perlu memeriksa kualitas tulisan peserta didik.
